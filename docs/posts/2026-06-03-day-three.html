Morning: Sorting Out the Blog

The day started with a small but satisfying detour. Looking back at the first two posts, it was clear that the blog needed a contents page — without one, there’s no easy way to navigate between days or get a sense of where the project is heading. A wall of individual posts with no map is fine when there are two of them, but it’s not going to scale.

So before any code, I spent the morning restructuring the blog files. Adding a proper contents page meant rethinking the layout — the individual .qmd files needed consistent YAML frontmatter so Quarto could list them properly, and the project itself needed to be treated as a website rather than a collection of standalone documents. It’s one of those jobs that feels fiddly while you’re doing it but pays off immediately the moment you render it and see a clean, navigable index page.

It’s also just good practice. A research blog that you can’t navigate is barely better than no blog at all.

Afternoon: Hunting for Oscillations

With the blog in better shape, I got back to the main task: trying to produce interesting dynamics in the single species mizer model.

The question from Day 2 had been nagging at me. The previous attempts at perturbing the size spectrum — bumping up abundance in different size ranges — kept converging back to steady state without producing anything that looked like a genuine oscillation or instability. The spectrum would wobble briefly and then flatten out again. Convincing yourself you’ve found something when you’ve just produced a slightly delayed equilibrium is a trap worth avoiding.

Today it finally clicked — and the fix was conceptually simple once I saw it.

The Key Insight: Resource Rate Is a Power Law

The resource replenishment rate in mizer isn’t a single scalar — it’s a function of size, following a power law:

\[r_{pp}(w) \propto w^{-\lambda}\]

When I’d been “reducing the resource rate” in earlier experiments, I’d been setting it to a constant. That’s not just a small reduction — it’s changing the shape of the function, not just its magnitude. You end up with a resource that replenishes at the same rate regardless of size, which is biologically wrong and dynamically different.

The correct way to reduce the resource rate while keeping the physics intact is to scale the existing power law — multiply the whole curve by a small scalar. This preserves the size-dependence while genuinely suppressing replenishment across the board:

p <- newSingleSpeciesParams(lambda = 2.05)

r <- resource_rate(p)       # extract the power law
r <- r * 0.0001             # scale it down uniformly
p <- setResource(p,
  resource_rate = r,
  resource_dynamics = "resource_semichemostat"
)

That single change — extracting the rate, scaling it, and putting it back — made all the difference.

Adding the Initial Perturbation

With the resource replenishment genuinely suppressed, I then bumped the initial fish abundance in the large size range (10–100 g) by a factor of 5:

rng <- c(10, 100)
idx <- p@w >= rng[1] & p@w <= rng[2]
initialN(p)[, idx] <- initialN(p)[, idx] * 5

This seeds a localised excess of fish at large body sizes — exactly the kind of perturbation that should reveal whether the system has an oscillatory or damped response.

The Full Experiment

library(mizer)
library(patchwork)
library(reshape2)
library(plotly)
library(dplyr)
library(mizerExperimental)
library(tidyverse)
library(glue)

# Deviation from power law diagnostic
deviation_plot <- function(sim, title) {
  spec <- finalNResource(sim)
  expected <- params@w_full^(-2.05)
  deviation <- spec / expected
  plot(params@w_full, deviation, type = "l", log = "x",
       main = title, xlab = "Size (g)", ylab = "Deviation from power law")
  abline(h = 1, lty = 2)
}

# Build params
p <- newSingleSpeciesParams(lambda = 2.05)

# Scale down resource rate as a power law (not a constant)
r <- resource_rate(p)
r <- r * 0.0001
p <- setResource(p,
  resource_rate = r,
  resource_dynamics = "resource_semichemostat"
)

# Perturb the large size range
rng <- c(10, 100)
idx <- p@w >= rng[1] & p@w <= rng[2]
initialN(p)[, idx] <- initialN(p)[, idx] * 5

# Run simulation
sim <- project(p, t_max = 100, t_save = 0.5)

# Diagnose
deviation_plot(sim, "Deviation — bump at large range")
animateSpectra(sim, resource = FALSE, log_x = FALSE, log_y = FALSE, power = 2)

The Result

It worked. The animated spectrum shows genuine oscillatory motion — the fish abundance doesn’t just relax monotonically back to equilibrium. Instead it oscillates, overshooting and undershooting in a way that’s visually unmistakable and numerically real. The fine time resolution (t_save = 0.5) was important here — without it the animation would smooth over the dynamics.

This is the kind of behaviour we need to study further. An oscillating size spectrum is potentially the signature of the instability described in Datta, Delius & Law (2011), and seeing it appear in mizer at all is the key prerequisite before we can start asking what fishing does to it.

What This Means

The Day 2 experiments weren’t wrong — they were just missing a critical detail. A resource rate that is reduced to a constant rather than scaled as a power law is a different model, not a lower-resource version of the same model. That distinction matters because mizer’s steady-state dynamics are calibrated around the power law structure: changing the shape breaks assumptions that the rest of the model depends on.

The lesson generalises: when you want to weaken a power law, multiply it — don’t replace it.

What’s Next

The immediate priorities are:

  • Characterise the oscillation — what is the period? How does it depend on the scaling factor applied to r? Is there a threshold below which the system goes from damped to oscillatory?
  • Map the parameter space — vary the size of the initial perturbation and the suppression factor together. Is the oscillatory regime a narrow window or a broad basin?
  • Connect to the theory — Datta et al. give explicit stability conditions in terms of \(\beta\), \(\sigma\), and \(K\). Can we reproduce those thresholds in mizer and confirm the analytic predictions hold?
  • Think about fishing — oscillatory dynamics that self-sustain without fishing are interesting, but the real question is whether selective fishing can nudge the system into or out of that regime.

Today felt like a genuine step forward. The oscillation is real, the mechanism is understood, and the path ahead is clearer than it was this morning.
